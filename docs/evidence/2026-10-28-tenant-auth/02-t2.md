### TA-31 · 前端登录态（浏览器五步）

浏览器面板不可见（`NATIVE_BROWSER_VIEWPORT_UNAVAILABLE: viewport=0x0`），**截图不可用**；
改用可访问性树 + 页面内 DOM 断言（偏差 D-8）：

| 步 | 实测 |
|---|---|
| 1 打开 `/` | `form / textbox 客户号 / textbox 口令 / button 登录`（不是空白、不是对话界面） |
| 2 错口令 | `{"message":"账号或口令不正确","userIdValue":"u-1","passwordValue":"wrong","stillLoginCard":true}`（一句、字段不清空） |
| 3 对口令 | `{"hasComposer":true,"hasLoginCard":false,"statusDot":"app-header__status is-online","logoutButton":["退出"]}` |
| 4 会话失效后操作 | 撤销会话 → 发消息（401）→ 自动 reload → `{"hasLoginCard":true,"hasComposer":false}`（不白屏） |
| 5 退出 | 点"退出" → 登录卡片；刷新 → `{"afterReloadLoginCard":true,"metaToken":false,"metaMode":"password"}` |

> 步 4 的"手动删 cookie"用**服务端撤销会话**等价替代：`bah_sid` 是 HttpOnly，
> 页面 JS 删不掉；撤销后下一次请求同样是 401，走的是同一条收敛路径。
