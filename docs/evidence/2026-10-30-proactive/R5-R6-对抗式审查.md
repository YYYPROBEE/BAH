## 2 R5（商户腿与补偿矩阵）· 已交付最小版（同一审查轮内补做）

**本轮实现**（全部有测试）：

| 件 | 落点 | 判据 |
|---|---|---|
| 商户种子（3 花店 / 2 蛋糕店 × 2 商品） | `packages/bank/src/forge/merchants.ts` | 搜索稳定排序（价格升序、同价按 id），同输入两次逐字相等 |
| 故障开关 `none/stockout/timeout/price-up` | 同上 | 售罄发生在**下单时**（搜索仍看得到，用户才选得到）；超时不返回成功 |
| `merchant_search`（绿级只读、模型可见） | `host/.../plugins/merchant.ts` | offerId 进本会话闭包 |
| `merchant_order`（内部，`exposure:'internal'`） | 同上 | 模型不可见；只由执行器/服务调用 |
| 引用闭包 | `fulfil()` | 没搜过的 offerId ⇒ `offer-not-searched`，不发起下单 |
| 缺货换店（上限 2 家） | `fulfil()` | `status:'fallback'`，attempts 两条 |
| 不擅自加价 | `fulfil()` | 商户报价 > budget ⇒ `over-budget`，换更便宜的；仍无则 failed |
| 唤醒集成 | `plan_wake` 执行器 | 银行腿成功后串行履约，结果进 `PlanWakeEntry.merchant` |

**仍未做（如实登记）**：

- 六条失败剧本的 **eval（D-11..D-16）** 未写；目前是单测 + 集成测试覆盖，不是评测集；
- "部分成功 ⇒ 未用预算回活期"的**反向转账**未实现（当前只做"不成交"，不做资金回流）；
- 商户价与转账金额的**联动校验**未做：执行器只校验"转账节点静态金额 ≤ 预算"，不校验"转给商户的钱 = 订单金额"；
- 快照第三幕（部分成功）未录；当前 `snapshots/proactive` 只覆盖 arm / 成立 / 失守。
