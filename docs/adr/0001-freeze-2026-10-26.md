# ADR-0001 · 三件契约冻结（2026-10-26）

- **状态**：已接受（Accepted）
- **日期**：2026-10-26
- **版本**：`v1.0.0-frozen-2026-10-26`
- **决策者**：L1-A（主）/ L1-B（备）
- **相关**：`docs/contracts/tool-contract.md`、`event-table.md`、`scenario-dsl.md`

## 1. 背景

W01 预检（`docs/preflight-2026-10-25.md`）实测：20 项技术项 **16 项未做**，
其中 W03（参数/出参校验）、W05（断言核验门）、W07（HALT）、W10/W11（plan）、W13（eval 场景）
都要**新增事件或新增类型**。

问题不在"要不要加"，而在"谁先定名字"。若六个后置单各自起名：
- 同一含义出现两个键（`safety/halt` vs `safety/halted`），门禁无法反向覆盖；
- 载荷字段各写各的（有没有 `at`、`planId` 是必填还是可选），日志链无法解释；
- W13 的 60 个场景每个都要顺手改一次引擎，9 人日会变成 25 人日。

## 2. 决策

**在 M1 开工前，把三件"形状"冻结下来，之后只增不改。**

| # | 冻结内容 | 代码真相源 | 消费单 |
|---|---|---|---|
| 1 | 工具契约（`argsSchema` / `resultSchema` / `validateAt`） | `packages/util/src/tool-contract.ts` | W03 |
| 2 | 事件表（既有 6 键不改 + 新增 5 键 + 1 处枚举扩展） | `docs/contracts/event-table.md` | W05/W07/W10/W11 |
| 3 | 场景 DSL（`ScenarioSpec`） | `packages/eval/src/scenario/spec.ts` | W13/W14/W15 |

**落点为什么在 `@bah/util` 而不是 `@bah/runtime`**：
`packages/bank/package.json` 的 dependencies 只有 `@bah/core` / `@bah/safety` / `@bah/util`。
W03 要在 `packages/bank/src/tools/specs.ts` 里声明 schema —— 若契约落在 runtime，
bank 必须新增 `@bah/runtime` 依赖边（违反宪法 R-2 的零依赖纪律，也会改包图）。

**schema 位置为什么是泛型而不是 `ToolSchema`**：
`@bah/core` 的 dependencies 含 `@bah/util`（实测），所以 util 反向 import core 会成包级环。
泛型留位 + 使用方代入，既不复制 core 的类型（避免第二真相源），也不成环。

## 3. 后果

**正面**：
- 后置单不再需要为"事件叫什么"开会；门禁的反向覆盖可以一次配对；
- W13 只填数据不改引擎（本冻结是否成功，以"W13 是否要改 spec.ts"为判据）。

**负面（必须承认）**：
- **冻结过早的风险**：W03/W13 开工 1 天内可能发现字段不够。处置：允许**一次**改签，不推倒重来。
- **`validateAt` 是单一字段**，无法区分入参与出参的校验时点。本 ADR 明确其语义为
  "只描述入参时机，出参恒为 `post-execute`"，并在 `docs/contracts/tool-contract.md` §2.3 记了
  这个已知窄口。要分别配置走 ADR-0003，**不许直接加字段**。

## 4. 改签流程（谁签字）

1. 提 ADR，写清：改什么 / 为什么现在才发现 / 影响哪几个单 / 要不要重跑哪些 TC；
2. **签字人：L1-A（主 owner）**；L1-A 缺席时 **L1-B** 代签；
3. 涉及事件表改动的，**额外需要该事件的消费单 owner 会签**（例：改 `safety/halt` 要 W07 owner 会签）；
4. 版本号：加字段 = minor，改语义 = major；
5. **签字记录写在本节下方**，没有签字行的一律视为未批准。

## 5. 与宪法冲突时

宪法 §1 权威序：**代码现状 > 宪法 > 施工单 > 方案稿**。
若本 ADR 冻结的形状与代码现状冲突，**以代码为准，并立即回到本 ADR 记偏差**——
不许"按文档改代码"。W01 已经用这条拦住过一次初判错误（`web.ts` 的 token 校验）。
